A Shrine to Lost Umbrellas

~*~ remembering the fallen, the forgotten, the left-behind ~*~ gone but not forgotten ~*~

Every umbrella anyone has ever lost deserves a eulogy, not a shrug. This is that eulogy, written one umbrella at a time. Somewhere out there is a drawer, a lost-property box, a skip behind a train station, full of umbrellas that someone once chose, carried, and then, on one ordinary and unremarkable day, simply walked away from. This site exists so that choice is not the last thing anyone remembers about them.

I started keeping a list of my own lost umbrellas a few years ago, mostly as a joke, and then it stopped being a joke. An umbrella is a strange object: you only ever notice it is gone once it starts raining again, which means every loss is discovered late, usually in a doorway, usually in a hurry. There is something honest about an object whose entire purpose is to be forgotten the moment the weather turns nice.

This site has four other rooms. About explains who is running this shrine and why. See the collection for individual umbrellas, each with a name and a story. Read the field notes for my ongoing, entirely unqualified observations about lost umbrellas as a category of object. And read the sightings page --- my own running log of umbrellas I've seen abandoned around town.
